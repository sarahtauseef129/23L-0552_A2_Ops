
# VisionGuard — AI vs Real Image Classification

[![VisionGuard CI](https://github.com/sarahtauseef129/23L-0552_A2_Ops/actions/workflows/visionguard-ci.yml/badge.svg)](https://github.com/sarahtauseef129/23L-0552_A2_Ops/actions/workflows/visionguard-ci.yml)

VisionGuard is an MLOps project for classifying images as
AI-generated or real using TensorFlow, MobileNetV2,
Flask, MLflow, DagsHub, Docker and PostgreSQL.
